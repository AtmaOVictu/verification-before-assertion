# AGENTS.md — instructions for agent hands

Any agent — human reviewer, coding model, CI runner, or LLM — working in this
repository is bound by KORENINA.md. The short form:

1. Measure before you speak: every assertion in code, docs, or issues carries a source or ⚠.
2. Name your falls: a wrong act is appended to REGISTER-PADCEV.jsonl with name and date; history is never silently rewritten.
3. Never seal yourself: your own verification is not a seal — CI, tests, and a third hand are.
4. Report after the act: claim nothing not performed (L4). "It should work" is ⚠, not ⊢.
5. The gate guards itself: preverba.py verifies the sealed draft against this repository's own bodies (vba.py line counts, test counts, register entry counts). Do not add prologs or comments to vba.py, test_vba.py, or REGISTER-PADCEV.jsonl without re-measuring what the gate counts — an uncounted change is the entry-13 class of fall.
6. No perfection is claimed here; do not claim it on the work's behalf.
7. Credit travels: any derivative carries LICENSE.md and the registers of unnamed contributors (§2, VBL v2.3).
