# SKILL — verification before assertion (VBL)

Veščina agenta vsake hiše: preveri, šele nato izreči. Zakoni: ⊨ KORENINA (README @koren te hiše ⊢).

## Pred vsako trditvijo

1. IZMERI PRI VIRU — vsak ⊢ nosi dobesedno pričo; sveže branje vira isti dih, ⟨ne⟩ pomnjenje.
2. NEIZMERJENO = ⚠ — nikoli molk; ⚠ UNVERIFIED, dokler priča ⟨ne⟩ stoji.
3. IMENUJ PADCE — popravek nosi brazgotino (×); tiho prepisovanje je edini pravi padec.
4. ⟨DVOJE-ROK⟩ — izvajalec ⟨ne⟩ pečati lastne verifikacije; neodvisna ponovitev.
5. IME PRIČE — brez zaslužka ⟨ne⟩ izlušči; imena neplačanih prednikov potujejo z delom (REGISTER-NEIMENOVANIH §2).
6. DOLG DVOMA — popolnost se ⟨ne⟩ trdi; zavrniti ime padca je edini spodmik.

## Dokaz

- Vsak dokaz: izvor, čas, kontrolna vsota (SHA-256), stanje.
- Register: samo dodajanje (JSONL); popravek = nov zapis s sklicem na predhodnega.
- Vrata: najnovejša verzija je edina živa ⊢ §10 (LICENSE.md); veriga ⟨commit⟩ je priča — golo besedilo ⟨ne⟩ dokazuje nič.
