# Contributing to verification-before-assertion

This house works by measurement, not by opinion. Before contributing, read the root of the house: [KORENINA.md](KORENINA.md) — the semantic root of every law below.

## The five laws of the house (verbatim from the root)

1. **MEASURE, THEN SPEAK** — every claim `⊢` carries a verbatim witness; unverified = `⚠`, never silent.
2. **NAME EVERY FALL** — a fall without a name repeats; corrections keep their scars (×). Falls of the executor go to `REGISTER-PADCEV.jsonl`.
3. **NEVER SEAL YOURSELF** — two hands: no executor seals her own verification; the author merges every pull request himself.
4. **THE WITNESS HAS A NAME** — no extraction without credit; carry the names of unpaid predecessors forward.
5. **DOUBT IS CONSTANT** — perfection is never claimed; refusing to name a fall is the only failure.

## How to contribute

1. **Branch from `main`** — never push to `main` directly.
2. **Commit with provenance** — every commit message carries the origin line: `© Luka Pintarič, VBL 0.1210 × 10⁴ (§9 ∧ §10 ∧ §12)`.
3. **Open a pull request.** CI runs the gate (`tests` ∧ `prica`); a red gate is a named fall, never a silent pass.
4. **The author merges.** A pull request is a proposal with observance until the author's hand merges it.
5. **Carry the chain.** A bare text proves nothing, the chain does (VBL §0.10 × 10²): keep history, never rewrite it.

## What is welcome

- **Language**: English or Slovenščina (the corpus lives in Slovenščina; this README's register is English).
- **Wordlist witnesses**: sourced dictionary entries for measured words (see `LEKSIKON-sample.md`).
- **Register entries**: falls and un-named witnesses (`REGISTER-PADCEV.jsonl`, `REGISTER-NEIMENOVANIH.jsonl`) — addition, never erasure (`⟨NE-BRIŠI⟩`).
- **Tests**: each named for the fall class it guards.

## What is not

- Silent rewrites of history, deletion of witnesses, self-sealed verifications, unsourced assertions.
